### 🚀 Wayground Pro Automator v4.0

A major desktop update introducing a native Windows interface, live automation controls, and reliable startup for tests already in progress.

#### ✨ Key Highlights in this release

- **Native Windows Interface**: Added a startup window, live panel, compact strip, and Settings. Rounded windows, light/dark themes, consistent controls, and readable answer cards replace the console as the default interface. Existing console workflows remain available with `--cli`.
- **Live Automation Controls**: Pause/resume, submit one answer with **Answer now**, schedule or undo a deliberate mistake, and switch checked AI engines for the next request. F2 hides/restores the overlay while automation continues, and Settings remain accessible in compact mode.
- **Start Tests Already in Progress**: Select an existing game tab and enter its PIN or game link. **AI only** can start after a real availability check without verified keys, an API question manifest, or a known question count; progress is read from the live test page.
- **Session-Bound Execution**: Automation stays attached to the selected game. Normal navigation within the same identified game is allowed; closing, reloading, or switching the target stops submission and requires fresh preparation. Stop and Exit leave the browser open.
- **Transparent Answer Status**: Current answer preserves the full text with wrapping and scrolling. Verified keys and AI predictions are labeled separately, with the actual provider and request time. Accuracy percentages appear only when supplied by Wayground results.
- **Variable Timing & Flexible Mistake Limits**: **Min delay** defaults to 10 seconds, with question-length timing and ±30% variation that never falls below the chosen minimum. Changes update the current countdown, and zero skips automatic waiting. The mistake limit can also return to zero, canceling pending mistakes while preserving submitted history.
- **Improved Quiz Discovery & Written Responses**: Exact-title searches check additional public-library pages and verify candidates against game questions. OPEN questions without fixed keys remain visible without discarding valid keys for other questions. The desktop run waits for your own written response and continues after submission; status messages are never inserted as answers.
- **Standalone Binary & Documentation Updated**: Rebuilt `WaygroundAutomator.exe` for v4.0 with bundled UI resources and version metadata. Updated the English and Russian README with five demo screenshots, current workflows, timing controls, and test/build instructions.

#### ✅ Validation

300 automated tests, 9 local browser checks, 10 gateway tests, and 44 interface checks of the compiled executable passed. Windows metadata verified: product version `4.0`, file version `4.0.0.0`.
